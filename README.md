# Anomaly detection using machine learning using data from Euclid
A repository for the coursework for the Data Intensive Physics unit at the University of Bristol. This project is identifying anomalies in Euclid, using the Euclid TILE 102158848. I will compare three anomaly detection methods using different aspects of the data along with their hardware requirements, and then create a model for one of the methods.

# Testing different models
Currently investigating using isolation forest, an autoencoder and local outlier factor with spectroscopic and photometric data from Euclid, as well as morphology labels from MOSAIC images. These tests will be done first will a sample of the tile, but will be scalable to the entire survey.
